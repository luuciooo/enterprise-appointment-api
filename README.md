# Enterprise Appointment API

Backend built with Spring Boot following Hexagonal Architecture (Ports & Adapters).

## Tech Stack

- Java 21
- Spring Boot
- PostgreSQL
- Flyway
- Docker
- Lombok
- Spring Security

## Architecture

This project follows Hexagonal Architecture to keep domain logic isolated from infrastructure.

## Running locally

```bash
docker compose up -d
mvn spring-boot:run
```
